# Cohort Retention Analysis

## Project Overview
This project analyzes customer purchasing behavior using cohort analysis to understand customer retention over time. Customers are grouped based on the month of their first purchase, and their activity in subsequent months is measured using retention percentages.

The project uses Python for data cleaning and visualization, along with SQL Server for cohort-based calculations and customer analysis.

## Project Objectives
- Analyze customer retention across monthly cohorts.
- Identify how customer purchasing activity changes over time.
- Calculate monthly retention percentages.
- Visualize retention patterns using a heatmap.
- Use SQL to analyze cohort activity and monthly new customers.

## Dataset
**Dataset:** Online Retail II

The dataset contains retail transaction records from two periods:
- Year 2009–2010
- Year 2010–2011

Important columns include:
- `Invoice`
- `Quantity`
- `InvoiceDate`
- `Price`
- `Customer ID`
- `Country`

## Project Workflow

### 1. Data Cleaning
- Combined the two Excel worksheets.
- Removed records with missing customer IDs or invoice dates.
- Converted invoice dates into datetime format.
- Excluded cancellation invoices.
- Removed records with non-positive quantities or prices.

### 2. Cohort Analysis
- Identified each customer's first purchase month.
- Assigned transactions to monthly cohorts.
- Calculated the number of months since each customer's first purchase.
- Counted distinct active customers in each cohort and month.

### 3. Retention Calculation
Customer retention was calculated using the following formula:

**Retention Rate (%) = (Customers Active in a Cohort Month / Original Cohort Size) × 100**

### 4. Data Visualization
Created a cohort retention heatmap to compare customer retention across cohorts and months.

### 5. SQL Analysis
Used SQL Server to:
- Identify each customer's first purchase month.
- Calculate monthly cohort activity.
- Calculate cohort retention percentages.
- Summarize monthly new customers.
